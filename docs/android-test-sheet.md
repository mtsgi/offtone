## Issue #7: キューと再生操作（実機未検証）

Android の機種・OS・Chrome バージョンと PWA インストール状態を記録する。

1. 複数曲を再生し、シークバーと音量をタッチ・キーボードで操作する。曲切替直後や読み込み中も試す。
2. シャッフルを切り替え、現在曲が途切れないことと、OFF 時にキューの並びに戻ることを確認する。
3. リピート OFF / ALL / ONE で曲末まで再生し、手動の次曲・前曲も試す。
4. キューの重複、移動、削除とフォルダー再スキャン中の再生維持を確認する。
5. 画面ロック・別アプリ表示中に通知、Bluetooth 機器の前後・再生停止・シークと表示位置を確認し、復帰後の表示を照合する。

## Issue #24: Now Playing 手動確認

- Chrome の通常タブとインストール済み PWA の両方で、音楽フォルダーを開いて再生する。ライブラリをスクロールした後、下部の曲情報から画面を開閉し、位置と再生が維持されることを確認する。再生ボタンだけでは画面が開かないことも確認する。
- 再生中に Android の戻るジェスチャー、閉じるボタン、連続した開閉を試し、PWA が終了せず二重に戻らないことを確認する。再読み込み後の戻る操作も確認する。
- 曲送り、曲末の自動遷移、タグ解析・アートワーク反映、キュー編集、ライブラリ更新を拡大画面を開いたまま試す。シーク、シャッフル、リピート、音量、ロック画面や Bluetooth の操作も確認する。
- アートワークなし・画像読み込み失敗・タグなしの曲を確認する。小さい画面、折りたたみ端末の開閉、回転、ライト・ダークテーマ、Android のジェスチャーナビゲーションと safe area を確認する。
- キーボードと TalkBack で画面の開閉、フォーカス復帰、主要操作、背景への移動防止を確認する。端末・OS・Chrome のバージョンと結果を記録する。
