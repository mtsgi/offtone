# 再生キューと操作

ライブラリは選択フォルダーの相対パス順、キューは一時的な項目 ID を持つ別のリストです。同じ曲を複数回追加できます。ID はメモリ内だけで使い、永続化しません。ライブラリの曲を選ぶとキュー内の最初の対応項目を再生し、存在しなければ追加します。

同じフォルダーの再スキャンでは相対パスで照合します。再生中の曲が残る場合は読み込み中を含め音源を維持します。キューを編集済みの場合、残った項目の重複・並びを維持し、新たに見つかった曲を末尾に追加します。現在曲が消えた場合や別フォルダーを選んだ場合は停止してキューを再構築します。異なるフォルダーの同名ファイルは相対パスで区別します。

シャッフル ON 時は現在項目を先頭にして残りをランダムに並べ、1 周まで各項目を一度ずつ再生します。追加項目は末尾に置きます。OFF にすると編集済みキューの並びに戻ります。シャッフル中の並べ替えは OFF 後の順序に適用します。前曲は再生順の直前へ移動し、先頭では何もしません。

リピート OFF は終端で停止、ALL は先頭へ戻り、ONE は自動終了時に同じ項目を再生します。手動の次曲は ONE を無視し、ALL のみ終端から先頭に戻ります。1 曲の ALL / ONE は自動終了時に再生し直します。空キューでは操作しません。現在項目を削除すると停止して選択を解除します。読み取りや再生に失敗した曲は再生順の後続を一度ずつ試し、再生許可の拒否は自動スキップせず再試行を待ちます。エラー時にはリピートで無限に再試行しません。

シークは有限かつ正の長さが分かり、音源の読み込みが完了した場合に有効です。位置は 0 と総時間の間に制限します。Media Session 非対応操作は無視します。Android 実機の手順は [android-test-sheet.md](android-test-sheet.md) を参照してください。
