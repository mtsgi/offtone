# 再生キューと操作

ライブラリは選択フォルダーの相対パス順、キューは一時的な項目 ID を持つ別のリストです。同じ曲を複数回追加できます。ID はメモリ内だけで使い、永続化しません。ライブラリの曲を選ぶとキュー内の最初の対応項目を再生し、存在しなければ追加します。

曲行の三点ボタンから「再生」「次に再生」「キューの最後に追加」「曲情報」を選べます。「次に再生」は現在項目の直後に新しい項目を挿入し、続けて追加すると最後に選んだ曲が次になります。現在項目がなければ先頭に挿入します。「キューの最後に追加」は常に末尾に追加します。どちらの追加操作も、現在の曲や再生位置を維持し、自動再生しません。

同じフォルダーの再スキャンでは相対パスで照合します。再生中の曲が残る場合は読み込み中を含め音源を維持します。キューを編集済みの場合、残った項目の重複・並びを維持し、新たに見つかった曲を末尾に追加します。現在曲が消えた場合は停止して選択を解除します。

前回の曲、再生位置、キューとシャッフル順、リピート、音量はフォルダー別に端末内へ保存します。アクセス権を確認してフォルダーを走査した後、保存したキューと曲を一時停止状態で表示します。再生ボタンを押すと、曲の長さに収まる範囲で前回の位置から再開します。削除や移動で見つからなくなった項目はキューから外れます。未編集のキューでは新曲を含めてライブラリ順に並び、編集済みのキューでは新曲を末尾に追加します。

曲の変更、キューの編集、一時停止時に保存し、再生中の位置は約 5 秒おきに保存します。PWA の更新による再読み込み前は保存を最大 2 秒待ちます。アプリを強制終了した場合、最後の保存以降の数秒分の再生位置が失われることがあります。

シャッフル ON 時は現在項目を先頭にして残りをランダムに並べ、1 周まで各項目を一度ずつ再生します。「次に再生」はシャッフル再生順と編集済みキューの両方で現在項目の直後（未選択時は先頭）に入り、「キューの最後に追加」は両方の末尾に入ります。OFF にすると編集済みキューの並びに戻ります。シャッフル中の並べ替えは OFF 後の順序に適用します。前曲は再生順の直前へ移動し、先頭では何もしません。

リピート OFF は終端で停止、ALL は先頭へ戻り、ONE は自動終了時に同じ項目を再生します。手動の次曲は ONE を無視し、ALL のみ終端から先頭に戻ります。1 曲の ALL / ONE は自動終了時に再生し直します。空キューでは操作しません。現在項目を削除すると停止して選択を解除します。読み取りや再生に失敗した曲は再生順の後続を一度ずつ試し、再生許可の拒否は自動スキップせず再試行を待ちます。エラー時にはリピートで無限に再試行しません。

シークは有限かつ正の長さが分かり、音源の読み込みが完了した場合に有効です。位置は 0 と総時間の間に制限します。Media Session 非対応操作は無視します。Android 実機の手順は [android-test-sheet.md](android-test-sheet.md) を参照してください。
