# Android 実機検証（Issue #4）

この手順は検証準備であり、実機での成功を示すものではありません。意図しない停止 0 回を目標とし、未達の場合は時刻・再現条件を記録してください。Codex の jsdom テストは Android のバックグラウンド再生、OS のメディア UI、Bluetooth、権限、オフライン起動を実証しません。

## 準備と記録

1. HTTPS の検証対象を Android Chrome で開き、ビルドの URL・コミット、端末、Android と Chrome のバージョン、バッテリー制限、Bluetooth 機器を記録する。端末内に MP3・M4A・FLAC と、連続 10 曲以上かつ合計 30 分以上のファイルを用意する。
2. 通常の Chrome タブで各試験を行い、同じサイトをインストールして PWA でも各試験を繰り返す。両方の結果を別々の [テストシート](android-test-sheet.md) に記入する。端末や Chrome がフォルダー選択に非対応なら、その事実とバージョンを記録し、依存する試験は未検証とする。
3. 画面の「診断ログ」で「記録を開始」を押す。ログはメモリのみ、最新 500 件、再読み込みで消える。停止後も表示・コピー・JSON 保存できる。曲番号はその記録中の匿名番号であり、再走査や消去後に変わり得る。記録開始前のイベントはない。
4. 画面ロックの直前・解除後に「操作時刻を記録」を使うか、端末の時刻とロック／解除時刻を手動でシートに記入する。visibilitychange は画面ロックの確実な検出手段ではない。ログの UTC 時刻と手動記録のタイムゾーンを照合する。
5. 問題発生後、再読み込みやアプリ終了の前にログをコピーまたは JSON 保存し、テストシートに保存先を記載する。ログは曲名・パス・音声データを含まず送信しないが、時刻や再生状況は含むため共有前に内容を確認する。必要に応じて消去する。

各試験の結果は成功／失敗／未検証とし、操作、期待・実際、発生時刻、再現条件、ログ参照を記録する。機能が表示されない・選択できない場合も成功とせず、環境とともに記録する。

## A. 基本再生

| 試験          | 操作                                      | 合格条件                                                          |
| ------------- | ----------------------------------------- | ----------------------------------------------------------------- |
| A1 フォルダー | フォルダーを選択し、一覧から曲を選ぶ      | 一覧が表示され選択曲が再生される                                  |
| A2 形式       | MP3、M4A、FLAC をそれぞれ選んで聴く       | 各形式が正常に再生される。ファイルのコーデックも記録する          |
| A3 操作       | 再生、一時停止、再開、前曲・次曲を操作    | 各操作と表示が一致する                                            |
| A4 連続曲     | 10 曲以上あるキューを先頭から自動再生する | 操作なしで 10 曲以上に遷移し、意図しない停止がない                |
| A5 長時間     | 時刻を記録し 30 分以上再生する            | 30 分以上継続し、意図しない停止がない。開始・終了時刻と曲数を記録 |

## B. バックグラウンド

各試験は再生を開始し、少なくとも曲の切り替わりを含む時間観察する。OS の省電力設定と経過時間を記録する。

| 試験                | 操作                                                 | 合格条件                                   |
| ------------------- | ---------------------------------------------------- | ------------------------------------------ |
| B1 ロック           | 画面をロックして聴き、解除する                       | ロック中に再生が継続し、復帰後も状態が合う |
| B2 他アプリ         | 音を出さない別アプリに切り替える                     | 他アプリ表示中も再生が継続する             |
| B3 ホーム           | ホーム画面に戻る                                     | 再生が継続する                             |
| B4 ロック中の曲送り | 曲の終盤にロックし次曲まで待つ                       | 次曲が自動再生される                       |
| B5 再開             | バックグラウンドで一時停止し、メディア操作で再開する | 停止後に同じ曲の位置から再開する           |

## C. Media Session

| 試験          | 操作                                                   | 合格条件                                                 |
| ------------- | ------------------------------------------------------ | -------------------------------------------------------- |
| C1 ロック画面 | ロック画面の再生・一時停止を各々押す                   | 音と再生状態が操作に一致する                             |
| C2 前後       | ロック画面で前曲・次曲を押す（キューの中間で実施）     | 各々隣の曲に切り替わる                                   |
| C3 通知       | 通知領域で再生・一時停止・前後を操作する               | 表示された各操作が正しく動作する                         |
| C4 Bluetooth  | イヤホンを接続し再生・一時停止・前後操作を行う         | 機器が提供する操作が正しく反映される。非搭載操作は未検証 |
| C5 表示同期   | 曲を切り替え、一時停止・再開してロック画面と通知を見る | 曲名と再生状態がアプリ・実際の音と一致する               |

## D. 復旧・例外

| 試験          | 操作                                                                                            | 合格条件                                                                        |
| ------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| D1 再起動     | ログを保存後、タブ／PWA を終了して再起動                                                        | 保存済みフォルダーが復元されるか再許可が案内され、許可後に再生できる            |
| D2 権限       | Chrome のサイト設定等で権限を失効させ再起動し、再許可する                                       | 再許可または再選択で復旧できる。失効を再現できない場合は未検証                  |
| D3 オフライン | オンラインで PWA を一度起動し準備後、ネットワークを切り完全終了して起動、フォルダーを開いて再生 | アプリが起動し、必要な権限を得て端末内の曲を再生できる。タブと PWA を別記録     |
| D4 音声競合   | 再生中に別アプリで音声を開始し、停止後 offtone に戻る                                           | 実際の中断・再開と表示が整合し、ユーザー操作で復旧できる。OS の挙動と時刻を記録 |
| D5 復帰       | 再生中にホームまたは別アプリへ移動し、数分後に復帰                                              | 曲・再生状態が実際の音と一致し、操作できる                                      |

OS・Chrome の省電力や音声フォーカス、コーデック、権限の実装によって結果は異なります。予期しない停止、表示の不一致、再生不能はログと手動時刻を添えて記録し、必要な修正を別途判断します。
